# kbeautysave-media

Public media host and generator for the @kbeautysave K-beauty content.
- `tools/` — reel (9:16 MP4 + synthesized royalty-free BGM) and Pinterest pin generator
- `specs/` — one JSON spec per day
- `media/YYYY-MM-DD/` — published files (reel.mp4, cover.png, pin.png)
- `RUNBOOK.md` — daily automation steps
